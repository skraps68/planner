- need the concept of proposed assignment edits that can be stored against a particular user as drafts. draft assignments can then be applied at any time, and the system will keep track of these. need to be able to group a bunch of assignments/re-assignments and even non-labor changes together into an edit (what should we call this edit set?) and assign a unique ID to the edit set. the system can then apply, generate a history of edits sets applied, and even roll back an edit, assuming other edits were not made over it (this could create conflicts and make it unclear what a rollback means). alternatively, the system could offer to rollback the edit set and all edit sets done since then?
